# 安装与首次运行故障排查

本文只覆盖安装、配置和首次启动问题。真实游戏识别准确率、模型质量和训练效果需要单独验证。

## Python 找不到或版本不对

现象：`python` 不是内部或外部命令，或版本低于 3.11。

处理：

1. 安装 64 位 CPython。
2. 安装时勾选 Add Python to PATH。
3. 重新打开 PowerShell 或 CMD。
4. 运行：

```cmd
python --version
```

需要 OCR/视觉依赖时，优先使用 64 位 CPython 3.12。

## 虚拟环境创建失败

现象：`.venv` 没有生成，或提示权限不足。

处理：

- 不要把项目放在 `C:\Program Files` 等受保护目录。
- 确认路径中没有被杀毒软件锁定的文件。
- 删除不完整的 `.venv` 后重新运行 `install.cmd`。

## 依赖安装失败

现象：pip 报 hash mismatch、timeout 或 build error。

处理：

- hash mismatch：不要跳过，先清理 pip 缓存后重试。
- timeout：检查网络代理或换用可访问 PyPI 的环境。
- build error：确认是否在安装 OCR/视觉依赖；先尝试基础依赖安装。

## OCR 组件不可用

现象：自检提示 OCR 包缺失或 Python 版本不兼容。

处理：

- 使用 64 位 CPython 3.12。
- 重新运行安装脚本的视觉/OCR 选项。
- OCR 失败不应阻止你阅读教程或运行 smoke 检查，但会影响 GUI 识别质量。

## 模型地址不可达

现象：模型连接失败、HTTP 404、401、403 或超时。

处理：

- 确认 base URL 是 OpenAI-compatible 根地址，例如 `http://127.0.0.1:1234/v1`。
- 确认模型名称与服务端一致。
- 云端服务需要 API Key，本地服务可能不需要。
- 401/403 通常是密钥或权限问题，不应无限重试。

## 找不到游戏窗口

现象：运行前确认窗口失败。

处理：

- 先启动游戏或模拟器。
- 确认窗口没有最小化。
- 确认标题、进程和运行配置匹配。
- 如果确认期间窗口被重建，请重新开始运行确认。

## 原生采集 DLL 不存在

现象：采集诊断提示找不到 DLL 或 SHA 不匹配。

处理：

- 普通安装不一定包含本地构建的 DLL。
- 开发者可运行 `scripts/build_native.ps1` 构建。
- 设置 `UGA_NATIVE_CAPTURE_SHA256` 时必须使用当前 DLL 的小写 SHA-256。

## 运行时没有动作

这可能是正常的保守拒绝。常见原因：

- 模型返回 WAIT/ABSTAIN。
- 完成证据不足。
- 最终画面显示控件禁用或目标消失。
- 当前页面是登录、支付、实名、协议、删除等敏感页面。
- 急停或租约已经撤销。

不要通过降低安全阈值来强制点击。先查看看板和日志中的拒绝原因。

## 我只想检查安装，不想操作游戏

使用：

```cmd
check.cmd
python -m apps.agent
uga-agent
```

不要启动真实运行入口。提示词里写“禁止操作”不能保证零输入。
