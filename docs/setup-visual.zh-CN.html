VLGameAgent 安装与首次运行图文教程

这是一份离线教程，不加载远程脚本，不会联网，也不会启动代理。

先读安全提示

真实运行前必须确认目标窗口、任务和模型配置。遇到登录、支付、实名、协议、删除等敏感页面，应人工处理。提示词里写“不要操作”不能把真实运行变成零输入模式。

1. 安装

在项目根目录运行：

install.cmd

安装脚本会创建项目内的 .venv 并安装锁定依赖。不要把项目放在需要管理员权限写入的位置。

安装菜单
基础安装
适合先跑教程和 smoke 检查
GUI + OCR
需要 64 位 CPython 3.12
运行自检
不抓图、不启用键鼠

2. 检查环境

check.cmd

检查项包括 Python、虚拟环境、依赖、OCR、工作目录和原生 DLL 摘要。检查不加载 DLL，不启用物理输入。

环境检查

Python：版本与位数

依赖：是否安装锁定包

模型：只检查配置，不发送截图

DLL：显示摘要，不执行库代码

3. 配置模型与任务

核心字段：

模型地址
http://127.0.0.1:1234/v1
模型名称
Qwen3-VL-4B-Instruct
glm-4.6v
任务
明确要做什么
完成证据
例如“出现已领取”

API Key 不应写入公开脚本、截图或日志。云端模型请只在运行环境中注入密钥。

4. 启动前确认

start.cmd --help

真正运行前，请确认：

  • 目标窗口不是敏感页面。
  • 窗口标题、PID、任务、模型地址与你预期一致。
  • 你知道急停：Ctrl+Shift+F12。
  • 从短时长开始，例如 60 秒。
运行确认

目标窗口：MuMu / 游戏窗口

任务：完成每日任务并领取奖励

模型：Qwen3-VL 或 GLM

输入 RUN 后继续取消

5. 不操作游戏的检查

只想确认安装是否成功时，使用这些命令：

check.cmd
python -m apps.agent
uga-agent

不要启动真实运行入口，也不要依靠提示词来阻止输入。
