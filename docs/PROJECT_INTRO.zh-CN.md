# Universal Game Agent 项目介绍文案

> 本页内容独立于 README，可直接用于项目主页、GitHub About、产品介绍、技术社区发布、演示材料或对外合作说明。

## 一句话介绍

Universal Game Agent 是一个安全优先的通用视觉游戏智能体运行时，让视觉大模型能够像人一样观察实时画面、理解界面、执行操作，并验证每一步是否真正生效。

## 项目短介绍

Universal Game Agent（UGA）是面向实时游戏与复杂图形界面的通用视觉智能体平台。项目通过窗口捕获、OCR、视觉语言模型、确定性策略、安全输入执行和动作效果验证，构建完整的“观察—理解—规划—操作—验证—恢复”闭环。它不依赖私有游戏接口、内存读取或代码注入，也不绑定特定游戏、引擎、模拟器或模型供应商。开发者只需提供目标窗口档案和 OpenAI-compatible 视觉模型，即可搭建具备实时理解、可控操作、故障恢复、运行看板与 Episode 记录能力的视觉操作智能体。

## 项目标准介绍

Universal Game Agent 是一套为视觉智能体打造的工程化运行基础设施，目标是解决“模型能看懂画面，却无法长期、稳定、安全地完成真实操作”的核心问题。

传统自动化通常依赖固定坐标、录制回放或预定义脚本，一旦分辨率、布局、弹窗或任务状态发生变化，流程便容易失效。UGA 将视觉语言模型的泛化理解能力与确定性规则的稳定性结合起来：模型负责识别开放世界中的页面、目标和下一步意图，规则层负责处理已经验证过的关键流程，执行层则在每次输入前重新检查窗口身份、画面时效、几何变化、焦点和安全约束。动作完成后，系统还会从新画面中判断预期效果是否出现，避免把“已经点击”误认为“任务完成”。

项目采用目标档案驱动设计。不同目标应用通过 YAML 描述进程、窗口、控制方式、禁点区域和敏感操作，无需修改通用运行时；本地或云端视觉模型通过 OpenAI-compatible 接口接入，也无需绑定单一厂商。对于成熟流程，开发者可以增加带页面锚点、预期效果、冷却和正反测试的确定性策略，同时保留模型对未知场景的理解能力。

UGA 还提供本地诊断看板、Episode 录制、确定性回放、执行回执、数据资格校验、样本导出、基准测试和可选训练流水线，使每一次运行都可以被观察、复现、审计和持续改进。它既可以作为视觉游戏 Agent 的完整运行平台，也可以作为计算机使用智能体、图形界面自动化、交互研究和多模态决策系统的基础工程。

## 项目长介绍

大模型已经能够理解复杂截图、阅读界面文字并给出合理的操作建议，但从“看懂”走向“可靠执行”，中间仍然缺少一整套系统工程：如何确保模型操作的是正确窗口？如何避免对过期画面执行动作？如何把模型描述的目标准确落到当前界面？如何判断一次点击是否生效？如何处理加载、动画、弹窗、页面跳转和失败恢复？如何在长时间运行中避免重复点击、输入残留、线程失控以及敏感操作？

Universal Game Agent 正是为这些问题而设计。

UGA 以窗口渲染画面作为主要信息来源，通过高速捕获和 OCR 构建结构化观测，再把当前画面、任务上下文和有限历史交给视觉语言模型或确定性策略。规划结果不会直接转换成系统输入，而是先经过目标落地、窗口身份、焦点、坐标空间、几何代次、帧新鲜度、禁点区域、敏感页面和控制租约等多层校验。只有通过安全门禁的动作才会进入执行器。执行后，系统重新捕获画面并验证状态变化；如果结果与预期不一致，智能体会重新观察、采用受限恢复动作或停止运行，而不是无上限重复尝试。

这种闭环设计让 UGA 与普通宏工具形成根本区别：它关注的不是“按顺序重放输入”，而是“基于当前可见事实持续作出可验证决策”。因此，它能够适应窗口位置、界面状态、任务顺序和视觉内容的变化，并允许通用模型能力与经过验证的局部规则共同工作。

在安全性方面，UGA 采用 fail-closed 原则。窗口切换、焦点丢失、画面过期、目标歧义、敏感词命中、动作超时、看门狗异常和执行效果缺失都会使输入被抑制或运行停止。登录、支付、购买、实名、删除、安装、交易、转移和账号设置等场景被明确划为人工处理边界。所有物理输入由统一执行器产生，模型本身无法绕过仲裁层直接操作系统。

在工程可观测性方面，UGA 提供本地实时看板，用于查看当前画面、OCR、任务、决策来源、目标位置、执行结果、安全拦截、延迟和运行健康度。Episode 系统能够记录观测、规划、动作、执行回执与最终结果，并支持确定性回放和数据资格校验，为问题复现、策略评审、离线评估和后续训练提供可靠依据。

在可扩展性方面，UGA 使用目标档案隔离窗口和控制配置，使用策略注册表隔离特定工作流，使用模型适配层连接不同视觉模型，使用 Skill 帮助其他 Agent 自动完成安装、配置、首轮验证和故障诊断。新目标可以从 model-first 模式快速开始，在积累足够证据后逐步沉淀为更稳定的规则路径，而无需破坏通用架构。

Universal Game Agent 希望提供的不只是一个可以“自动点击”的程序，而是一套面向真实世界视觉操作的可靠运行标准：每一步都基于当前画面，每一个动作都有明确授权，每一次成功都有可验证证据，每一次失败都能够被追踪和恢复。

## 核心亮点

- **通用性**：不绑定特定游戏、引擎、模拟器、UI 布局或模型厂商。
- **纯视觉**：从窗口画面和 OCR 工作，不依赖私有接口、内存读取或进程注入。
- **闭环控制**：每次动作后重新观察并验证效果，拒绝无脑连点和脚本式假成功。
- **安全执行**：窗口、焦点、帧、坐标、敏感页面、租约和看门狗多层防护。
- **模型与规则协同**：兼顾未知场景的泛化能力和成熟流程的确定性。
- **全链路可观测**：实时看板、事件记录、执行回执、Episode 和确定性回放。
- **数据可复用**：支持数据资格校验、样本导出、基准测试和可选训练流程。
- **Agent 友好**：提供完整 Skill、启动脚本、目标模板和可转发安装提示词。

## 适用场景

- 经授权的游戏视觉智能体研究与测试；
- 多模态计算机使用 Agent 原型；
- 复杂 GUI 的视觉理解与受控操作；
- 无障碍交互与辅助操作研究；
- 视觉决策数据采集、回放与评估；
- 本地或云端视觉模型的真实交互能力验证。
